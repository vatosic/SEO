# Этап 1. Исследование источников данных для SEO-системы

Дата проверки: 16.11.2026. Цены и условия проверялись по официальным страницам, где это удалось.
Если источник сторонний, это отмечено. Перед любой оплатой цены надо перепроверить.

---

## 1. Бесплатные официальные источники (данные о своём сайте)

### Google Search Console (API)
**Что даёт:**
- Запросы, страницы, страны, устройства: показы, клики, CTR, средняя позиция.
- Проверка индексации отдельных URL (URL Inspection API).
- Список sitemap.

**Ограничения:**
- Хранит историю только за 16 месяцев. Значит, выгрузку надо начинать сразу и хранить у себя.
- Не больше 50 000 строк в день на сайт и тип поиска. Редкие («анонимизированные») запросы не показываются.
- Квоты: Search Analytics — 1 200 запросов в минуту на сайт; URL Inspection — 2 000 в день и 600 в минуту на сайт.
- Позиция «средняя», по всем регионам вместе; нет данных о конкурентах.

Источники: [квоты](https://developers.google.com/webmaster-tools/limits), [лимит 50 000 строк](https://developers.google.com/search/blog/2022/10/performance-data-deep-dive).

### Яндекс Вебмастер (API v4)
**Что даёт:**
- Популярные запросы: до 500 строк за вызов из топ-3000 запросов за период; показы, клики, средняя позиция показа и клика; фильтр по устройствам ([документация](https://yandex.ru/dev/webmaster/doc/ru/reference/host-search-queries-popular)).
- Мониторинг запросов (query-analytics): пары «запрос — страница», показы, клики, CTR, позиция, спрос; фильтры по регионам и устройствам. История — только последние 2 недели, поэтому выгружать нужно регулярно. Лимит — 10 000 вызовов в час ([документация](https://yandex.ru/dev/webmaster/doc/ru/reference/host-query-analytics)).
- Расширенная выгрузка запросов по URL (бета): до 100 вызовов в день, до 100 URL за вызов ([документация](https://yandex.ru/dev/webmaster/doc/ru/reference/enhanced-export)).
- Индексация, ошибки, sitemap, внешние ссылки, переобход страниц.

**Ограничения:** короткая история по части методов, данных о конкурентах нет.

### Яндекс Метрика (API отчётов и Logs API)
**Что даёт:** трафик, поведение, цели, конверсии по страницам входа. Logs API выгружает «сырые» визиты за прошлые дни, до 1 года за один запрос ([документация](https://yandex.ru/dev/metrika/ru/logs/)).

**Ограничения:** поисковые фразы из органики Яндекса почти не передаются. Запросы берём из Вебмастера, а из Метрики — что делали люди на сайте после перехода.

### Wordstat API (частотность запросов)
- Методы: топ запросов за 30 дней, динамика, распределение по регионам; фильтры по регионам и устройствам ([структура API](https://yandex.ru/support2/wordstat/en/content/api-structure)).
- Сейчас работает через Yandex Search API в Yandex Cloud и стоит денег (см. ниже). Старый бесплатный доступ по заявке, по сторонним источникам, закрыт.

### Чего не хватает в официальных источниках
1. **Точных позиций по региону и дате** (у Google и Яндекса только «средняя позиция»).
2. **Данных о конкурентах**: их запросов, видимости, страниц.
3. **Снимков выдачи (SERP)**: кто стоит в топе, какие там блоки.
4. **Частотности для новых запросов**, по которым сайт ещё не показывается.
5. **Длинной истории**: в Яндексе 2 недели по части методов, в Google 16 месяцев.

## 3. Топвизор и DataForSEO

### Топвизор
- Оплата за проверки + необязательная подписка ради скидки: S 999 ₽ (−10%), M 2 990 ₽ (−15%), L 9 990 ₽ (−20%), XL 29 990 ₽ (−30%) в месяц.
- Позиции: 0,09 ₽ за проверку без подписки. Яндекс проверяется до 250 позиций на ПК и до 50 на смартфоне, Google — до 100.
- Частотность 0,02 ₽ за ключ; снимки выдачи, конкуренты, аудит, кластеризация — отдельные цены.
- API бесплатный. Ограничения: до 10 000 результатов за вызов, до 5 одновременных вызовов с одного IP и с одного аккаунта ([документация API](https://topvisor.com/api/v2/intro/)). Ключ API выдают после пополнения баланса.
- Топвизор сам предупреждает: проверки через Yandex Search API днём ограничены, лучше запускать их с 00:00 до 04:59 по Москве.

### DataForSEO: нам не подходит
1. **Правила (обновлены 12.06.2026, пункт 6.2):** сервисом нельзя пользоваться, если вы находитесь, зарегистрированы или проживаете в России или Беларуси ([Terms of Service](https://dataforseo.com/terms-of-service)). Запрет касается и места, где находится пользователь, а не только плательщика. Поэтому договор через казахстанскую компанию проблему не решает, если сервисом фактически пользуются из России. За нарушение аккаунт автоматически блокируют (п. 8.1).
2. **Данные:** с 07.03.2022 Россия и Беларусь убраны из всех API, на такие запросы возвращается ошибка; API выдачи Яндекса закрыт без замены ([объявление](https://dataforseo.com/update/russia-and-belarus-api-locations)).
3. **Вывод:** даже при законном доступе DataForSEO не даёт главного для vbi.ru — Яндекса и регионов России. Исключаем его из плана.

## 4. Важное замечание про Claude
Anthropic официально не работает в России и Беларуси ([список стран](https://www.anthropic.com/supported-countries)); Казахстан, Узбекистан, Армения и Грузия в списке есть. Как и с DataForSEO, важно, кто и откуда фактически пользуется сервисом. Это нужно честно учесть, когда будем решать, где работает система и кто ею управляет.
