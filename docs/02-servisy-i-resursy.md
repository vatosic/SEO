## 5. Карты и отзывы (локальное SEO)

- **Яндекс Бизнес:** API для карточек и отзывов нет. Есть фид XML/CSV для сетей филиалов. Отзывы обрабатываются только в кабинете.
- **2ГИС:** API для владельцев и отзывов не нашли, работа через «2ГИС Бизнес».
- **Google Business Profile API:** доступ по заявке. В России верификация не гарантирована, в СНГ работает.
- **Вывод:** карты ведём вручную, а система только напоминает и готовит ответы на отзывы. Ботов для работы с кабинетами не делаем.

## 7. Хранение, отчёты, сервер

- **Базы:** PostgreSQL (проекты, задачи) + ClickHouse (позиции, статистика). Бесплатные, ставятся на свой сервер.
- **Сервер в РФ:** Selectel от ≈ 950 ₽/мес; Timeweb Cloud: 2 ядра / 4 ГБ — 5 480 ₽/мес (есть площадка в Алматы).
- **Дашборды:** Yandex DataLens: 1 пользователь бесплатно, дальше 990 ₽/мес за место.
- **Looker Studio и выгрузку GSC в BigQuery не закладываем:** нужен биллинг Google Cloud, а российские карты не принимаются. GSC забираем через API в свою базу.

## 8. Право

- **152-ФЗ:** система не должна собирать персональные данные (заявки, телефоны, e-mail). Если такие данные появятся, их нужно хранить только в РФ. Позиции и статистика GSC персональными данными не являются. [обзор — сверить с юристом]
- **Маркировка рекламы:** обычные статьи на своём сайте маркировать не нужно. Платные статьи со ссылками на чужих площадках требуют erid и отчёта в ОРД. [обзор — финально решает юрист]
